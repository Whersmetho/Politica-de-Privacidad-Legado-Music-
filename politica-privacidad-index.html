1. Información que podemos recopilar

Legado Music está diseñado para funcionar dentro de Discord y puede procesar determinada información necesaria para proporcionar sus funciones.

  • ID de usuario de Discord: utilizado para identificar al usuario que ejecuta determinados comandos.
  • ID del servidor: utilizado para identificar el servidor en el que se utiliza el bot.
  • ID de canal: utilizado para determinar dónde debe responder o funcionar una función.
  • ID de mensajes: cuando sea necesario.
  • Nombre de usuario o nombre mostrado: cuando sea necesario para una interacción.
  • Configuraciones del servidor: preferencias relacionadas con el bot.
  • Información relacionada con comandos: comandos y parámetros necesarios.
  • Información técnica y de errores: para detectar problemas o fallos.

Legado Music no solicita deliberadamente contraseñas, números de tarjetas de crédito, documentos de identidad ni información financiera.

2. Información que no recopilamos intencionalmente

  • Contraseñas de Discord.
  • Tokens de cuentas de Discord.
  • Información bancaria o financiera.
  • Mensajes privados de los usuarios.
  • Datos personales sensibles que no sean necesarios.
  • Contenido de conversaciones privadas fuera de los canales donde interactúa el bot.

3. Uso de la información

La información procesada puede utilizarse para ejecutar comandos, reproducir y administrar contenido musical, mantener configuraciones, recordar preferencias, detectar errores, prevenir abusos, mantener la seguridad y mejorar el rendimiento.

4. Comandos y mensajes

Legado Music puede procesar los mensajes que contengan comandos dirigidos al bot y los datos necesarios para interpretarlos. Por ejemplo: /play nombre de una canción.

No almacenamos deliberadamente el contenido completo de las conversaciones cuando no es necesario para proporcionar una función.

5. Reproducción de música y servicios externos

Legado Music puede utilizar servicios, APIs o plataformas externas para proporcionar funciones relacionadas con la búsqueda o reproducción de música. Dichos proveedores pueden procesar determinada información técnica.

6. Almacenamiento de datos

La información necesaria puede almacenarse durante el tiempo que sea necesario. Los datos de configuración pueden mantenerse mientras el bot permanezca instalado o sean necesarios para el servicio.

7. Eliminación de datos

Los administradores pueden solicitar la eliminación de datos asociados al funcionamiento del bot en su servidor. Un usuario también puede solicitar la eliminación de datos personales cuando corresponda. Algunas informaciones podrán conservarse cuando sea necesario por motivos legales, de seguridad o prevención de abusos.

8. Seguridad

Tomamos medidas razonables para proteger la información frente a accesos no autorizados, pérdida, alteración o divulgación. Ningún servicio conectado a Internet puede garantizar una seguridad absoluta.

9. Menores de edad

Los usuarios deben cumplir los requisitos de edad y las condiciones de Discord y las leyes aplicables en su jurisdicción.

10. Compartición de información

No vendemos ni alquilamos información personal. La información podrá compartirse cuando sea necesario para proporcionar funciones, utilizar servicios técnicos, mantener la seguridad, cumplir obligaciones legales o investigar abusos.

11. Cookies y tecnologías similares

Legado Music, como bot de Discord, no utiliza cookies dentro de Discord para identificar personalmente a los usuarios. Una web externa puede utilizar cookies necesarias para su funcionamiento.

12. Cambios en esta Política

Podemos modificar esta Política para reflejar cambios en Legado Music, sus funciones, servicios utilizados o requisitos legales. Se actualizará la fecha de última actualización.

13. Contacto

Para preguntas o solicitudes relacionadas con datos, contacta mediante los canales oficiales de soporte: soporte@legadomusic.com.

14. Aceptación

Al añadir, configurar o utilizar Legado Music reconoces que has leído y comprendido esta Política. Si no estás de acuerdo, puedes dejar de utilizar el servicio y retirar el bot.
